高频面试题清单（第 24 周逐题演练）

  • ReAct 自由循环、固定 Workflow、HITL 各适合什么场景？如何取舍？（你的 demo5→8→9 就是答案线）
  • Coding Agent 为什么必须“先观察后修改”？如何用工具设计和提示词约束它？
  • 完整讲一遍 RAG 链路（加载→切分→向量化→入库→检索→生成），每个环节有哪些调优手段？
  • 如何评估一个 Agent 的好坏？轨迹评估和结果评估分别怎么做？
  • 如何控制 Agent 的成本与延迟？（上下文管理、模型分级、缓存、并行工具）
  • MCP 解决了什么问题？和直接写本地函数有什么本质区别？
  • Agent 的安全隐患有哪些？prompt injection 怎么防？
