demo7
Coding Agent
核心理念
先观察、后修改coding agent 必须先看代码，再决定是否修改
受限工作区只允许操作 demo7/project_workspace
安全替换expected_occurrences 校验匹配次数，防误改
最小改动小规模、精确、可验证的 patch
架构复用
CodingAgentRuntime继承 demo6 AgentRuntime，不复制框架
只通过覆写少数方法做场景化定制
coding_agent_demo.py入口：构建工具表 + 启动多轮对话
coding_runtime.py / coding_tools.py运行时定制与代码工具实现
三处定制
系统提示词先观察再修改；未看到真实工具结果不许声称已修改；工作区只限 project_workspace
create_state()把 workspace_dir 注入 shared_context
build_runtime_message()调度消息明确要求：修改前先定位并读取相关代码
观察型工具
list_files先看目录里有什么
search_text按关键字搜索代码内容
search_files_by_name按文件名定位文件
read_text_file读具体内容，确认目标后再动手
修改型工具
replace_text_in_file精确替换 old_text → new_text，校验 expected_occurrences
write_text_file创建或重写完整文件（谨慎使用）
标准工作流
① 先看目录 list_files
② 搜文件或关键字 search_*
③ 读具体内容 read_text_file
④ 做精确修改 replace / write
实战与练习
示例工作区project_workspace/ 下的 app.py、settings.py、utils.py、README.md
练习：给 greet_user 的空名字增加更友好处理
练习：把 DEFAULT_THEME 从 light 改成 dark
练习：让 Agent 定位并总结某段业务逻辑的作用
